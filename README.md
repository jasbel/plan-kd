# 🎨 Plan-KD: Generador de SVG para E-commerce

Crea imágenes vectoriales (SVG) de productos para tu tienda en línea y descárgalas en un archivo ZIP. ¡Perfecto para e-commerce y catálogos digitales!

## 🚀 Demo en vivo

**[Abre la aplicación aquí](https://jasbel.github.io/plan-kd/)**

## ✨ Características

- 📦 Genera múltiples imágenes SVG de productos de forma automática
- 🎯 10 categorías diferentes de productos (Electrónica, Moda, Hogar, Belleza, etc.)
- 📐 Múltiples tamaños disponibles: 400x400, 600x600, 800x800, 1024x1024 px
- 🏷️ Opción de incluir etiquetas de precio
- 💾 Descarga todas las imágenes en un archivo ZIP
- 🎨 Vectores de alta calidad en formato SVG
- ⚡ Completamente offline - funciona en tu navegador

## 🛠️ Tecnologías

- HTML5 vanilla
- CSS3
- JavaScript puro
- [JSZip](https://stuk.github.io/jszip/) para generar archivos ZIP

## 📋 Cómo usar

1. Abre la [aplicación web](https://jasbel.github.io/plan-kd/)
2. Configura:
   - Cantidad de imágenes a generar
   - Tamaño de las imágenes
   - Categorías de productos
   - Si deseas incluir etiquetas de precio
3. Haz clic en **"Generar imágenes"**
4. Haz clic en **"Descargar ZIP"** para descargar todas las imágenes
